# CyberIntel

CyberIntel is a machine learning project for analyzing cybersecurity vulnerabilities and calculating risk scores.

## Features
- Vulnerability analysis
- Machine learning risk scoring
- Interactive Streamlit dashboard
- Search, filtering, and CSV export

## Installation
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

## Run
streamlit run app.py

## Disclaimer
Risk scores are estimates, not definitive security assessments.
